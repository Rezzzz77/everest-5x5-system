# آواتار تصویری پلنگ برفی (اختیاری)

اپ به‌صورت پیش‌فرض آواتار را با **سیلوئت SVG** رسم می‌کند (بدون هیچ فایل تصویری،
کاملاً آفلاین و سبک). اگر تصاویر واقعی پنج مرحله را دارید، فقط فایل‌ها را با این
نام‌ها در همین پوشه بگذارید و در `src/leopard.js` مقدارها را فعال کنید:

```
assets/leopards/
├── stage-1.png   ← تولهٔ نوزاد        (CUBLING  · سطح ۱)
├── stage-2.png   ← تولهٔ در حال رشد   (POUKLE   · سطح ۱۰)
├── stage-3.png   ← نوجوان             (TRAINEE  · سطح ۲۵)
├── stage-4.png   ← جوان بالغ          (VANGUARD · سطح ۵۰)
└── stage-5.png   ← پلنگ نگهبان        (GUARDIAN · سطح ۱۰۰)
```

سپس در `src/leopard.js`:

```js
export const LEOPARD_IMAGES = {
  1: 'stage-1.png',
  2: 'stage-2.png',
  3: 'stage-3.png',
  4: 'stage-4.png',
  5: 'stage-5.png'
};
```

## مشخصات پیشنهادی تصویر

| مورد | مقدار |
|---|---|
| نسبت | مربع (۱:۱) |
| اندازه | ۲۵۶×۲۵۶ یا ۵۱۲×۵۱۲ |
| پس‌زمینه | شفاف (PNG) |
| حاشیهٔ امن | ۸٪ از هر طرف، تا در قاب گِرد بریده نشود |
| حجم | زیر ۸۰KB برای هر مرحله |

## رفتار اپ

- اگر فایل موجود و سالم باشد → تصویر نمایش داده می‌شود.
- اگر فایل ۴۰۴ یا خراب باشد → **خودکار** به سیلوئت SVG برمی‌گردد (UI خالی نمی‌ماند).
- اگر می‌خواهید تصاویر آفلاین هم کار کنند، نام فایل‌ها را به فهرست `PRECACHE`
  در `sw.js` اضافه کنید.
