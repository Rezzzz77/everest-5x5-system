# آواتار تصویری پلنگ برفی (فعال)

این پوشه تصاویر واقعی پنج مرحله را نگه می‌دارد و در `src/leopard.js` فعال است
(`LEOPARD_IMAGES`). اگر فایل نبود یا بارگذاری‌اش شکست خورد، اپ خودکار به
**سیلوئت SVG** برمی‌گردد تا UI هرگز خالی نماند.

```
assets/leopards/
├── stage-1.png   ← تولهٔ نوزاد        (CUBLING  · سطح ۱)
├── stage-2.png   ← تولهٔ در حال رشد   (POUKLE   · سطح ۱۰)
├── stage-3.png   ← نوجوان             (TRAINEE  · سطح ۲۵)
├── stage-4.png   ← جوان بالغ          (VANGUARD · سطح ۵۰)
└── stage-5.png   ← پلنگ نگهبان        (GUARDIAN · سطح ۱۰۰)
```

سپس در `src/leopard.js`:

```js
export const LEOPARD_IMAGES = {
  1: 'stage-1.png',
  2: 'stage-2.png',
  3: 'stage-3.png',
  4: 'stage-4.png',
  5: 'stage-5.png'
};
```

## مشخصات تصاویر فعلی

| مورد | مقدار |
|---|---|
| نسبت | مربع (۱:۱) |
| اندازه | ۳۸۴×۳۸۴ |
| پس‌زمینه | شفاف (PNG، آلفا) |
| حاشیهٔ امن | ۶٪ از هر طرف |
| کیفیت | بدون کوانتیزه — ۱۵۲۵+ رنگ |
| حجم | ۱۰۷ تا ۱۹۱KB برای هر مرحله (مجموع ۷۵۷KB) |

رنگ‌های آلفا بررسی شده‌اند: در عمق بدن هر پنج تصویر `alpha = 255` است و هیچ
حفرهٔ بسته در خز وجود ندارد.

### غیرفعال‌کردن

در `src/leopard.js` همهٔ مقدارهای `LEOPARD_IMAGES` را `null` کنید؛ سپس آواتار
به سیلوئت SVG برمی‌گردد.

## رفتار اپ

- اگر فایل موجود و سالم باشد → تصویر نمایش داده می‌شود.
- اگر فایل ۴۰۴ یا خراب باشد → **خودکار** به سیلوئت SVG برمی‌گردد (UI خالی نمی‌ماند).
- پنج تصویر در فهرست `PRECACHE` فایل `sw.js` هستند، پس آفلاین هم بار می‌شوند.
  با هر تغییر تصویر، نسخهٔ `CACHE` در `sw.js` را هم بالا ببرید.
